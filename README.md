# Simple Counter

Simple Counter adds a personal counter panel to RuneLite.

## Features

- Create, select, and remove named counters.
- Increase or decrease a counter, set it to a number, or reset it to zero.
- Calculate a trip count by dividing a total goal by the amount per trip. The result is rounded up and set on the selected counter.
- Reset all saved counters from the plugin configuration's reset action.

Counter values are saved in RuneLite's local configuration for the current profile.
